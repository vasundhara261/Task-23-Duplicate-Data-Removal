Duplicate Data Removal Using Pandas

## 📌 Project Overview
This project demonstrates how to identify and remove duplicate records from a dataset using Python and the Pandas library.

## 🎯 Objective
The objective of this project is to perform a basic data-cleaning technique before data analysis and modeling.

## 🛠️ Tools Used
- Python
- Pandas
- Jupyter Notebook

## 📊 Project Steps
1. Created a sample dataset containing duplicate records.
2. Identified duplicate records using `duplicated()`.
3. Counted the number of duplicate records.
4. Removed duplicates using `drop_duplicates()`.
5. Compared the dataset size before and after cleaning.
6. Saved the cleaned dataset as a CSV file.

## 📈 Results
- Rows before cleaning: 5
- Duplicate records found: 2
- Rows after cleaning: 3

## 💡 Conclusion
Removing duplicate records is an important data-cleaning step. It helps improve the accuracy and reliability of data analysis and machine learning models.
